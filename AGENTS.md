## Commands

- Install dependencies with `npm install`.
- Start local development with `npm run dev`.
- Run formatting with `npm run format` (Prettier uses 100-column lines, semicolons, double quotes, and trailing commas).
- Run lint with `npm run lint`.
- Run TypeScript checking with `npx tsc --noEmit`.
- Run the production client, SSR, and Nitro build with `npm run build`.
- On Windows PowerShell systems where script execution blocks `npm`, use `npm.cmd` and `npx.cmd` equivalents.

## Architecture

- This is a TanStack Start + React 19 + TypeScript app. `src/routes/__root.tsx` is the app shell and keeps `<Outlet />` in the main content path.
- The portfolio is structured across **exactly five routes**:
  - `src/routes/index.tsx` (`/`) — Ultra-minimal centered identity anchor.
  - `src/routes/work.tsx` (`/work`) — Premotio-inspired spatial narrative + 27-repo public catalog.
  - `src/routes/about.tsx` (`/about`) — Ethiack / Screenshot 1 scanner moment + compact factual bio.
  - `src/routes/notes.tsx` (`/notes`) — Ellipsus-style authored essay on instruments & calculus.
  - `src/routes/contact.tsx` (`/contact`) — Screenshot 2 light/ceramic card + direct email.
- `src/routeTree.gen.ts` is generated by TanStack Router. Never edit it manually.
- `src/components/site` owns shared chrome, navigation, and page interaction.
- `src/server.ts` is the configured SSR entry through `vite.config.ts`.
- `src/start.ts` explicitly installs error and CSRF middleware for server functions.
- `src/router.tsx` enables TanStack Router scroll restoration and uses a fresh React Query client per router instance.

## Motion

- GSAP is the primary motion system. Reuse `src/components/site/motion.ts` and scoped `useGSAP` contexts.
- No idle requestAnimationFrame loops: all particle canvases, tweens, and interactive elements must stop frames when settled.
- Progressive enhancement: Full compliance with `prefers-reduced-motion: reduce`. Content must render statically and legibly if animations or JavaScript are disabled.
