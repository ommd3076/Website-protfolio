## Commands

- Install dependencies with `npm install`.
- Start local development with `npm run dev`.
- Run formatting with `npm run format` (Prettier uses 100-column lines, semicolons, double quotes, and trailing commas).
- Run lint with `npm run lint`.
- Run TypeScript checking with `npx tsc --noEmit`; there is no dedicated `typecheck` script.
- Run the production client, SSR, and Nitro build with `npm run build`.
- On Windows PowerShell systems where script execution blocks `npm`, use `npm.cmd` and `npx.cmd` equivalents.
- There is no repository test suite or test script; use lint, TypeScript, build, and focused browser/responsive checks for verification.

## Architecture

- This is a TanStack Start + React + TypeScript app. `src/routes/__root.tsx` is the app shell and must keep `<Outlet />` in the main content path.
- Routes are file-based under `src/routes`: `/`, `/work`, `/approach`, `/future`, and `/contact`. Do not create a Next.js-style `src/pages` tree.
- `src/routeTree.gen.ts` is generated by TanStack Router. Never edit it manually; adding/removing route files updates it through the normal dev/build tooling.
- `src/components/site` owns shared chrome and page interaction; `src/components/brand` owns the reusable SVG logo component; `src/styles.css` owns Tailwind v4 theme variables and global motion/cursor styles.
- `src/server.ts` is the configured SSR entry through `vite.config.ts`; do not add the standard TanStack/Vite plugins manually because `@lovable.dev/vite-tanstack-config` already supplies them.
- `src/start.ts` explicitly installs error and CSRF middleware for server functions. Preserve both when changing server wiring.
- `src/router.tsx` enables TanStack Router scroll restoration and uses a fresh React Query client per router instance.

## Motion

- GSAP/ScrollTrigger is the primary motion system, with Lenis and the fine-pointer `mouse-follower` enhancement already wired at the root. Reuse `src/components/site/motion.ts` rather than adding another animation library.
- Every timeline, ScrollTrigger, event listener, and pointer enhancement must clean up on unmount and respect `prefers-reduced-motion`; avoid competing tweens on the same transform property.
- Motion is progressive enhancement: substantive content must remain visible if JavaScript or animation initialization fails. Do not add unconditional CSS opacity hiding.
- Keep ambient motion selective and page-specific. Do not add constant decorative motion, random blobs, scroll-jacking, or logo animation theatre.

## ReUI design rules (every UI edit, follow-ups included)

This project uses an existing design system: ReUI on shadcn/ui. Keep its look. Generic frontend advice (vary fonts or themes, gradients, page-load or staggered reveals, "2-3 intentional motions", Framer Motion) does not apply here, and other design skills lose where they disagree.

1. Use installed components first (`components/ui`, `components/reui`): tables `data-grid`, filtering `filters`, boards `kanban`, modals `Dialog` or `AlertDialog`, toasts `sonner`. Never set height, radius, padding, shadow or motion on them; use `size`, `variant`, `spacing`.
2. Color: semantic tokens. State: `<Badge variant="success-light">` from `@/components/reui/badge` at default size, or Alert variants. Raw palette only for categorical identity, with its `dark:` pair.
3. Spacing: `gap-*` on the parent: `gap-1` to `gap-2` in a row, `gap-3` to `gap-4` between groups, `gap-6` to `gap-8` between sections. Type: `text-sm` body, `text-xs` meta, nothing smaller; never resize FrameTitle or CardTitle.
4. Motion: installed parts already animate; never retime them. Yours: hover `transition-colors`; reveal `duration-200 ease-[cubic-bezier(0.22,1,0.36,1)]`; transform and opacity only; never `transition-all`, bounce, or a stagger on table rows or lists of 20+; at most 1 entrance per view; `MotionConfig reducedMotion="user"` plus `motion-reduce:`.
5. Every data region: empty state with an action, `Skeleton` loading, inline error with Retry.
6. Before UI code, write the plan from `.agents/skills/reui/SKILL.md` in your reply. Before you finish, run its self-check on the files you changed and fix every hit (2 rounds at most). Full rules: `.agents/skills/reui/SKILL.md`. If that folder is missing, call the `reui` MCP tool `get_agent_skill`.

Managed by the ReUI installer. Edits between the markers are replaced on the next run.
